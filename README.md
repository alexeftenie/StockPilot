# StockPilot

An AI assistant for stock and production planning. Ask questions in natural language
("Which materials are below minimum stock?", "Which production orders are delayed?") and get
an answer together with the data table it is based on. It runs on sample data only: a small
synthetic dataset or Microsoft's AdventureWorks sample database.

See [PROJECT_PLAN.md](PROJECT_PLAN.md) for the idea and architecture.

## How it works

1. The question goes to the LLM together with a list of **tools** (the analysis functions).
2. The LLM picks a tool and its parameters. It never writes SQL.
3. The parameters are validated, the Python/pandas function runs against SQLite and returns a table.
4. The table goes back to the LLM, which writes the answer **only from that result**.
5. The chat shows the answer plus every table that was used.

Two LLM backends are supported: **Ollama** (local, free) and **Claude** (Anthropic API).

## Project structure

```
app.py                    Streamlit chat interface
stockpilot/
  config.py               settings from .env
  db.py                   SQLite schema and helpers
  generate.py             synthetic data generator
  adventureworks.py       AdventureWorks downloader and importer
  analysis.py             analysis functions (pandas + SQL)
  tools.py                tool definitions and parameter validation
  assistant.py            LLM tool-calling loop (Claude and Ollama)
tests/                    pytest tests (no LLM needed)
```

## Available analyses (tools)

| Tool | Answers |
| --- | --- |
| `materials_below_min_stock` | Which materials are below minimum stock? (optional category) |
| `delayed_production_orders` | Which production orders are late? |
| `late_purchase_orders` | Which supplier deliveries are late? (optional supplier) |
| `supplier_performance` | On-time rate, short deliveries and rejection rate per supplier |
| `material_requirements` | Do we have enough material for the planned orders starting soon? |
| `stock_value_by_category` | Inventory value per category |
| `find_material` | Details for a specific material |

## Datasets

| `STOCKPILOT_DATASET` | Content |
| --- | --- |
| `synthetic` | 36 materials, 120 production orders, 150 purchase orders, generated by `generate.py` |
| `adventureworks` | Microsoft AdventureWorks: 406 materials, 238 products, 2,383 BOM lines, 72,591 work orders, 6,701 purchase order lines, 104 vendors |

AdventureWorks is imported as a snapshot on **2025-05-20**. Work orders starting after that date
are *Planned*, orders still running are *In progress*, and the rest are *Completed*. Materials are
BOM components and purchased items, grouped as *Subassembly*, *Purchased part* and *Resale item*.
Minimum stock is `SafetyStockLevel`. AdventureWorks does not record when purchase orders were
received, so supplier on-time rates are empty for this dataset. Supplier quality comes from the real
received and rejected quantities.

The importer downloads the needed CSV files from
[microsoft/sql-server-samples](https://github.com/microsoft/sql-server-samples/tree/master/samples/databases/adventure-works/oltp-install-script)
into `data/adventureworks/` on first run:

```powershell
python -m stockpilot.adventureworks
python -m stockpilot.adventureworks --today 2025-03-01
```

## Setup (Windows / PowerShell)

Install Python and the dependencies:

```powershell
winget install -e --id Python.Python.3.12
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
copy .env.example .env
```

Install Ollama and the local model:

```powershell
winget install -e --id Ollama.Ollama
ollama pull qwen2.5:7b
```

Build the database, run the tests and start the app:

```powershell
python -m stockpilot.adventureworks
python -m pytest
python -m streamlit run app.py
```

For the synthetic dataset, set `STOCKPILOT_DATASET=synthetic` and run `python -m stockpilot.generate`.
The app also builds the selected database automatically if it is missing.

The chat opens at http://localhost:8501.

Use `python -m ...` instead of `pip`, `pytest` or `streamlit` directly: the `.exe` launchers
break when the project path contains spaces (for example OneDrive folders).

## Configuration (.env)

| Variable | Default | Meaning |
| --- | --- | --- |
| `STOCKPILOT_DATASET` | `synthetic` | `synthetic` or `adventureworks` |
| `STOCKPILOT_PROVIDER` | `anthropic` | `ollama` or `anthropic` |
| `STOCKPILOT_OLLAMA_MODEL` | `qwen2.5:7b` | Local model used with Ollama |
| `STOCKPILOT_OLLAMA_NUM_CTX` | `8192` | Context window for the local model |
| `ANTHROPIC_API_KEY` | - | Claude API key (only for `anthropic`) |
| `STOCKPILOT_MODEL` | `claude-opus-5-5` | Claude model |
| `STOCKPILOT_EFFORT` | `medium` | Claude reasoning effort: low, medium, high, xhigh, max |
| `STOCKPILOT_DB` | depends on dataset | Overrides the database path |
